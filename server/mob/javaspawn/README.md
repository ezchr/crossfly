# server/mob/javaspawn

Java Edition natural spawning and despawning for Crossfly's Java mob mode
(`mobs=java`): Paper 26.3 with its default configuration, so mob farms built
for Paper work the same. Bedrock mode (`server/mob/spawn`) is independent.

```go
import "github.com/df-mc/dragonfly/server/mob/javaspawn"

javaspawn.SetRegistry(reg)            // the Java mob base (constructors per type)
javaspawn.RegisterHook()              // once, only in Java mob mode
javaspawn.Enable(w, javaspawn.Config{}) // natural spawning in w (Paper defaults)
javaspawn.SetDespawning(w, false)     // despawning is on in every world otherwise
```

Nothing of this package runs before `RegisterHook`, so `mobs=off|bedrock`
pay nothing. Sources are cited per function (decompiled vanilla 26.3 and the
Paper 26.3-244 jar); `data_gen.go` is generated by `internal/gen/gen.py` from
the vanilla data (worldgen/biome natural_mob_spawns, worldgen/structure
spawn_overrides, tags) and `EntityTypes.java`, then gofmt'd.

## Paper defaults used

| Setting | Value |
|---|---|
| `entities.spawning.per-player-mob-spawns` | true |
| bukkit.yml `spawn-limits` (per player) | monster 70, creature 10, ambient 15, axolotls 5, underground water creature 5, water creature 5, water ambient 20 |
| bukkit.yml `ticks-per` | animal-spawns 400, all others 1 |
| `despawn-ranges` | hard = MobCategory despawn distance (128, water ambient 64), soft 32, shape ellipsoid (= sphere) |
| `count-all-mobs-for-spawning` | false (only NATURAL / CHUNK_GEN mobs count) |
| spigot `mob-spawn-range` | 8 |
| server.properties `simulation-distance` | 10 |
| `slime-spawn-height` | surface biome 50..70, slime chunk below 40; `seed-slime` 987234911 |
| `monster-spawn-max-light-level` | default (dimension's block light limit) |
| phantoms | attempts every 60..119 s, insomnia 72000 ticks, not over creative players |

## What is implemented

Per world tick (`ServerChunkCache.tickChunks` order):

1. **Counting** (`NaturalSpawner.createState`, `ChunkMap.updatePlayerMobTypeMap`):
   every Java mob that is not persistent (`isPersistenceRequired`,
   `requiresCustomPersistence`), not misc and spawned naturally counts for
   every player whose simulation distance (square, 10 chunks) covers its
   chunk; mobs with a biome spawn cost add their charge (`PotentialCalculator`).
2. **Categories** (`getFilteredSpawningCategories`): game tick divisible by
   ticks-per, limit not 0, monsters only off peaceful (and the
   `NoMonsters` game rule), creatures only every 400 ticks.
3. **Chunks** (`collectSpawningChunks`, `isChunkNearPlayer`): loaded chunks
   whose centre is closer than 128 blocks (mob-spawn-range 8) to a
   non-spectator player, within the simulation distance.
4. **Per chunk and category** (`spawnForChunk`): the room left under the
   fullest cap of the players around the chunk; `spawnCategoryForChunk`: a
   random column, y uniform from the bottom to the WORLD_SURFACE heightmap;
   `spawnCategoryForPosition`: start not a redstone conductor, 3 packs of
   ceil(4·rand) steps (then the spawner's count) wandering
   `nextInt(6)-nextInt(6)` per step, distance > 24 from the nearest player
   and the world spawn, spawner pick (`getRandomSpawnMobAt`, reduced water
   ambient in some biomes), `isValidSpawnPostitionForType` (despawn
   distance, `canSpawnMobAt`, placement, spawn rules, no block collision),
   spawn potential budget, `isValidPositionForMob` (the mob's
   `checkSpawnRules` = walk target value, `checkSpawnObstruction`), cluster
   limits (`getMaxSpawnClusterSize`, `isMaxGroupSizeReached`), group data
   passed between pack members.
5. **Despawning** (`Mob.checkDespawn` with Paper's ranges): peaceful removes
   monsters; beyond the hard range at once if `removeWhenFarAway`; beyond
   the soft range 1 in 800 per tick after 600 idle ticks; within it the
   no-action timer resets. No player in the world: nothing despawns.
6. **Phantoms** (`PhantomSpawner`) and the time since rest (insomnia).

Spawn placements and rules (`SpawnPlacements`) for all 26.3 types: on
ground / in water / in lava / no restriction, `isValidSpawn` with every
`Blocks.java` override (glass, leaves for ocelots and parrots, ice for polar
bears, magma for fire-immune mobs, trapdoors, soul sand, ...),
`isValidEmptySpawnBlock` (full blocks, signal sources, rails, dangerous
blocks per type), the monster light rule (sky light vs rand(32), block light
limit, raw brightness with sky darkening from `timeline/day.json` and
weather, thunder darkening 10, per-dimension light test), animals on their
block tags with raw brightness > 8, slimes (swamps by moon phase, slime
chunks from the Java seed), drowned (rivers 1/15, oceans 1/40 below sea
level - 5), guardians, glow squid, fish, turtles, bats, strays, husks,
striders, ghasts, endermites/silverfish, pillagers. Biome lists use the Java
biome Crossfly sends Java clients (`javamap`). Structure lists (witch huts,
monuments, fortresses incl. the nether brick rule, outposts) apply when the
server gives `Config.Structures`.

Exported helpers for mob packages: `IsValidSpawn`, `IsValidEmptySpawnBlock`,
`IsSpawnPositionOk`, `AnyPlayerCloseEnoughForSpawning`, `IsSlimeChunk`,
`Type`, `PlacementOf`, `BiomeName`.

## Not implemented / differences

- Structures: Crossfly worlds store none, so without `Config.Structures`
  only biome lists apply (no witch hut witches, monument guardians,
  fortress blazes/wither skeletons, outpost pillagers).
- Chunk generation spawns (`spawnMobsForChunkGeneration`), patrols
  (`PatrolSpawner`), the wandering trader, village sieges and cat spawners
  are not ported (patrols/traders/cats: the raids and villagers rows).
- Sea level: 63/32/0 by dimension unless `Config.SeaLevel` (a Java
  superflat world has -63).
- Local difficulty (phantoms) ignores chunk inhabited time (not tracked).
- Light comes from Dragonfly's (Bedrock) light engine; water and leaves dim
  sky light as Bedrock does.
- Chunk order: Paper keeps its ticking-chunk list order; here a random start.
- `noCollision` checks block shapes only (no boats/shulkers, no world border).
- Player view distance below 8 is not considered (Paper: min(mob-spawn-range, view distance)).

## Tests

`go test -tags crossfly_full ./server/mob/javaspawn/`: defaults, generated
data, biome mapping, slime chunks against java.util.Random reference values,
sky darkening, the monster light rule's exact probabilities, placement types
on 13 floor kinds plus water/lava, per-type rules (animals at night, monsters
at noon/peaceful/dark, walk target), pack sizes and weights, cluster limits,
removeWhenFarAway, the creature cycle, the per-player cap (70, eggs and
persistent mobs not counted, two players two caps), a statistical test of
the spawn rate in a dark area against the independently computed Java
expectation, open-sky animals, despawn rules (hard/soft range, 1/800 rate,
water ambient 64, peaceful, off), phantoms and local difficulty.
